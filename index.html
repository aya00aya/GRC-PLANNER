How to use this planner
  • Open the current week, work top to bottom, and tick a task only when its deliverable exists.
  • Progress saves in this browser only. Use ← → on the tab bar to switch phases.
  • The last Sunday of each phase (Weeks 4, 9, 14) is a catch-up day. Use it to finish, not to add.
  • Falling behind? Drop the lightest task of each day for a week; never skip project deliverables.
  • Honest goal: interview-ready for entry-level GRC, not an expert. Exam fees apply to SC-900, Security+ and ISO 27001.
